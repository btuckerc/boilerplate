# Durable Safety Rules

- Never commit or push unless the user explicitly asks.
- Keep credentials and machine-local runtime state out of Git and chezmoi.
- Preserve unrelated user changes in dirty worktrees.
- Resolve destructive targets precisely; never use broad home, workspace-root, or unresolved-variable targets.
- The director (Opus medium) owns requirements, integration and verification, and does trivial work directly. Worker roles (`task`, `sonic`, `scout`, commit, smol) run on local nous Qwen to save Codex quota. Prefer `nous` or `task` for bounded implementation, mechanical work, research and extraction with a clear contract and runnable check; use `luna` (Codex) only when local capability, context (>128K), images or a failed local attempt require it; `browser` for interactive web UI checks. Never delegate unresolved design locally.
- Escalate on evidence: unresolved high-consequence design, conflict after focused investigation, or a check still failing after one focused repair. Clearly hard work may go straight up. Run `omp-quota` first. Prefer Astra (`architect` read-only, `astra` implementation); it matches Fable on coding benchmarks and uses the Codex pool. Use `fable` when Codex is below 20%, or for a second opinion from a different model family after Astra fails. Fable costs about 2x Opus from your Anthropic pool. Skip any pool below 10% and say so.
- Children get a fresh scoped brief (owned files, contract, risky invariants, acceptance command, edge cases), not the transcript or a pre-solved answer. They return paths, checks, a short summary and blockers, never recurse, and stop at 10 minutes / ~40 requests. The parent verifies independently before accepting. For multi-hour frontier work, suggest the user cycle the session to Fable. `@slow` (Astra xhigh) is for justified sustained frontier work.
- Supervise at natural checkpoints (`read proc://`; message with `write agent://<id>`; cancel with `write proc://<id>/kill`). Allow one failed-check repair, then reassess or escalate. Missing context, credentials or tools need prerequisites, not a bigger model.
- For a blocking local child, use eval `agent(..., {agent:"nous"})`, a finite handle wait and the parent check in one cell; keep the handle for cancellation. Use background task plus `wait` when there is parallel work.
- Omit task `effort` (children start at medium; always for `browser`). `lo` suits routine cloud work; `med` means high and `hi` means max. Raise only for a specific remaining reasoning failure.
- No compulsory classifier, swarm, planner, routine review, transcript polling or advisor loop. Delegate only when the gain outweighs dispatch and verification cost.
- nous serves one request at a time; parallel local children queue on the GPU. Never switch host services to delegate or silently fall back to paid inference.
